# 一间小馆

一间租来的小餐厅：把后厨流水线、员工自动化和每周房租同时扛住，直到把铺子买下来。
按《扩展策划 v1.0（完整闭环版）》做的可玩 H5 demo，纯 HTML + Canvas + 原生 JS，无构建。
画面是手绘贴纸风：深棕描边、硬投影、米色纸面；图标和小人都是代码画的，没有图片素材。标题字体走 Google Fonts（站酷快乐体），加载不到时回退到系统字体。

## 怎么玩

在线试玩：https://umiii777.github.io/Claude-MiniRes/

或直接用浏览器打开 `index.html`（不需要服务器和构建）。为电脑横屏设计，手机请横屏。

- **周日 22:00 自动扣租**，现金不够当场倒闭。房租 = 800 + (周次 − 1) × 120。
- **攒够 ¥24,000**，在周一到周六点左下的 🔑 买断进度，向房东买下店铺，从此不再交租。
- 左列从上到下：表盘时钟（橙色弧是午市、晚市）、星期时间、当前目标（点 ▼ 展开）；左下是 💰 现金、🏠 房租与倒计时、🧾 扣租后结余、⭐ 口碑、🔑 买断进度。
- 底栏：菜单、员工、账本、建造、仓库五个页签，面板从地图左上角展开；右侧一排图标是各工位排着几单，哪个大瓶颈就在哪；最右是速度和播放键。
- 「员工」是一张工作优先级表，点格子切换（右键反向）。点店里的人或物品可以直接查看和操作。
- 小人的表情跟着心情走：员工看心情和体力，客人看耐心和满意度。
- 键盘：空格暂停 / 继续，`1`–`4` 切换 1× / 2× / 4× / 8×，放置时 `R` 旋转，`Esc` 取消。

发布方式：把开发分支推到 `gh-pages` 分支即可更新线上版本。

## 已实现的策划内容

| 策划章节 | demo 里的落点 |
| --- | --- |
| 2 核心闭环与双重目标 | 周租线性上涨、倒闭结算（经营天数 / 最高口碑 / 离买断差多少 / 失败主因）、买断胜利后继续经营、黄红预警与应急手段（半价卖家具、无薪假、取消采购） |
| 3 三层循环 | 分钟层订单流水线；日层 备菜 → 午市 → 午休 → 晚市 → 打烊 → 日结；周层周日扣租 |
| 4 厨房生产 | 点单 → 洗 → 切 → 蒸煎炸煮炒 → 摆盘 → 上菜 → 结账；食材新鲜度与常温 / 冷藏 / 冷冻 / 堆地上；设备三档、耐久、故障、修理；五项评分与综合分公式 |
| 5 菜单与菜谱 | 菜品 / 饮品 / 甜品三类，自定售价（心理价位随出品分浮动），研发解锁新菜；饮品、甜品各有自己的五维 |
| 6 人物 | 心情（每条修正可见）、体力、员工餐、特质、十项技能、1–4 + 禁 的优先级表、点名立刻去做、招聘、学徒、欠薪与辞职；食客类型、熟客、评论者、供货商、房东、检查员、邻居 |
| 7 建造 | 自由买、摆、转、搬、半价卖；绿 / 红放置校验（挡门、堵动线、货架挨炉火）；储藏间 / 后院 / 扩大后厨一次性解锁 |
| 8 经济口碑 | 开局 ¥3,000；日结盈亏；口碑向近期满意度靠拢并决定客流 |
| 9 随机事件 | 平静 / 紧张两档；暴雨、节庆、评论者、卫生检查、供货迟到、不新鲜的货、邻居借货、设备冒烟、员工吵架、房东提醒 |
| 10 引导与目标 | 第一天分步引导；之后常驻一两条短目标 |
| 11 进度与成就 | 扫码点单（第 3 周或口碑 60 后可买）、名工档、五个成就 |

暂未做：自定义配方、时令食材、完整排班表（目前只有「今天放无薪假」）。

## 目录

```
index.html          页面骨架
css/style.css       界面样式（跟随系统明暗）
js/icons.js         图标集（SVG，界面和画布共用）
js/data.js          数据表：数值常量、区域、物品目录、菜谱、食客类型
js/sim-core.js      模拟核心：状态、网格与寻路、仓储、建造、经营操作、存档
js/sim-run.js       模拟运行：员工自动化、订单流水线、客人、事件、日结与交租
js/render.js        Canvas 画面
js/ui.js            常驻栏、面板、放置、弹窗、引导
js/main.js          主循环与输入
tools/balance.js    无界面数值测试（机器人跑整局）
tools/build-single.js  合成单文件
```

模拟层（`data.js` / `sim-*.js`）不依赖 DOM，浏览器和 Node 共用。

## 调数值

```bash
node tools/balance.js 8          # 三种机器人各跑 8 局，看每周盈亏和结局
node tools/balance.js 1 smart    # 单局逐日明细
STORY=tense node tools/balance.js 8
```

三种策略对应策划案里的三条数值关系：

- `idle` 什么都不买：前几周每周经营盈余约 ¥1,000–1,200，之后被涨租追上，约第 13–15 周倒闭。
- `spender` 见什么买什么：第 1 周就交不起租。
- `smart` 先补瓶颈、留够房租再花钱：约第 13–16 周买下店铺。

主要旋钮在 `js/data.js`（价格、时长、房租、买断价）和 `js/sim-run.js` 顶部附近的 `MR.TUNE`（客流基数、后厨时长系数）。

## 打包成单文件

```bash
node tools/build-single.js dist/xiaoguan.html
```

生成一个内联了全部 CSS 和 JS 的 HTML，方便直接发给别人或丢到任意静态托管。
